# MIMUW Projects
Here is collection of my favorite projects, written during my first year of studying at CS at University of Warsaw. 

## [`Totolotek Lottery System(Java)`](/totolotek/)
A Java-based simulation of a lottery system, featuring ticket generation, random draws, and result checking, mimicking the Polish Totolotek lottery.

## [`Moore Automata Simulator(C)`](/moore/)
A simulator for Moore automata, allowing users to define states, transitions, and outputs, and perform various operations on input strings to observe how states and outputs evolve step by step.

## [`Dynamic Signal Handler(C + Assembly)`](/signal-handler/)
A program demonstrating dynamic handling of UNIX signals, combining C and assembly to manage custom signal responses and manipulate process behavior.

## [`Square root function(x86-64 Assembly)`](/nsqrt/)
An implementation of the square root calculation using x86-64 assembly, focusing on low-level optimization and manual floating-point operations.
